# ARCAI Monetization Roadmap

## Phase 1 — Free (Launch)
- Chat platform with Standard + Test modes
- Build simple tools, convert code, learn Arc
- No signup required
- Goal: adoption, feedback, prove the concept

## Phase 2 — Free with Signup
- Unlock more complex builds (dashboards, games, mini apps)
- Save your projects
- Usage limits for free tier
- Goal: build user base, collect emails

## Phase 3 — ARCAI Pro ($49/mo individual, $199/mo teams)
- Build full websites and web apps in Arc
- One-click deploy
- Custom domains
- Higher rate limits
- Priority model (better AI for paying users)
- Export code
- Project history and versioning

## Phase 4 — ARCAI Business ($499/mo+ or project-based)
- Enterprise code conversion services (audit codebase → migrate to Arc)
- Consulting packages
- Dedicated support
- Custom integrations
- SLAs
- Project-based contracts $5K-50K+ depending on scope

## Phase 5 — ARCAI Platform
- Marketplace for Arc templates/components
- Revenue share with creators
- Arc plugin ecosystem
- API access for other platforms to integrate Arc
